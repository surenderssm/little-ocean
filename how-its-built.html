How little ocean works

On your screen

little ocean

A browser game made with HTML, CSS and JavaScript, with original Canvas artwork and touch-friendly controls.

Platform

Azure App Service Builder

The code is on GitHub at surenderssm/little-ocean, and the repo is connected to Azure App Service Builder for hosting.

The Python app uses Azure Blob Storage for adventure stats and Application Insights for telemetry. Builder connections can supply supported settings.

Autoscaling is configured to scale to zero when idle and scale with CPU and memory usage.
